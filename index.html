FlashCards de Matemática

Revise conceitos importantes de matemática.

Pergunta 1

Qual é a fórmula de Bhaskara?

Resposta

x = (-b ± √Δ) / 2a

Pergunta 2

Como calcular o delta?

Resposta

Δ = b² - 4ac

Pergunta 3

O que é porcentagem?

Resposta

É uma razão com base 100.

Pergunta 4

Quanto é 2³?

Resposta

2³ = 8

FlashCards de Física

Revise conceitos iniciais de física.

Pergunta 1

Qual é a fórmula da velocidade média?

Resposta

Vm = ΔS / ΔT

Pergunta 2

O que é força?

Resposta

É uma interação capaz de alterar o movimento de um corpo.

Pergunta 3

Qual é a unidade de força?

Resposta

Newton, representado pela letra N.

Pergunta 4

O que é aceleração?

Resposta

É a variação da velocidade em relação ao tempo.

FlashCards de Química

Revise conceitos iniciais de química.

Pergunta 1

O que é átomo?

Resposta

É a menor parte de um elemento químico.

Pergunta 2

O que é molécula?

Resposta

É a união de dois ou mais átomos.

Pergunta 3

O que indica pH menor que 7?

Resposta

Indica uma solução ácida.

Pergunta 4

O que indica pH maior que 7?

Resposta

Indica uma solução básica.
